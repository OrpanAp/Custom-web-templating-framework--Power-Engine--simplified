Good to know

Before you build.

Is POWER 2.0 the same as POWER 1.0?

No. POWER 1.0 is a client-side templating and SPA routing experiment. Version 2.0 is a Node.js web framework with server-side application tooling.

Do I need to install dependencies?

The framework currently declares zero runtime dependencies. You still need a supported Node.js installation and may need database setup for your integration.

Can I use MySQL or PostgreSQL?

Connection URL formats are supported in configuration, but verify the driver and integration against your actual database server.

Is it production-ready?

The project is in active development. Review the source, security configuration, deployment checklist, and documented limitations before production use.
