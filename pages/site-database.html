Database & models

Configure database connections, write parameterized queries, define models, and manage schema migrations.

Connection URLs

SQLite is the default for local development. Set DB_URL in your environment file to configure a connection.

DB_URL=sqlite:storage/power.sqlite
# PostgreSQL
DB_URL=postgres://USER:URL_ENCODED_PASSWORD@127.0.0.1:5432/DATABASE
# MySQL
DB_URL=mysql://USER:URL_ENCODED_PASSWORD@127.0.0.1:3306/DATABASE
# MariaDB
DB_URL=mariadb://USER:URL_ENCODED_PASSWORD@127.0.0.1:3306/DATABASE

URL-encode special characters in credentials, use TLS for remote databases, and run integration tests against the database server you plan to use.

Parameterized queries

import { db } from '../core/database.js';

const rows = await db.all(
  'SELECT * FROM users WHERE role = ?',
  ['admin']
);
const user = await db.get(
  'SELECT * FROM users WHERE id = ?',
  [5]
);
await db.run(
  'UPDATE users SET name = ? WHERE id = ?',
  ['Ada', 5]
);
Always bind values with placeholders. Do not concatenate user input into SQL. Table and column names should be validated using the framework's identifier helpers.

Transactions

await db.transaction(async (tx) => {
  await tx.run('UPDATE accounts SET balance = balance - ? WHERE id = ?', [10, 1]);
  await tx.run('UPDATE accounts SET balance = balance + ? WHERE id = ?', [10, 2]);
});

Inside the transaction callback, use tx for database operations; mixing in the global connection can wait on the transaction lock.

Migrations

node bin/power-cli.js make:migration create_posts_table
node bin/power-cli.js db:migrate
node bin/power-cli.js db:status
node bin/power-cli.js db:rollback

Models

import { Model } from '../../core/model.js';

export class Post extends Model {
  static table = 'posts';
  static fillable = ['title', 'body'];
}

Use the model API to create, find, list, update, and delete records. Test PostgreSQL and MySQL connections against your actual server before production use.

Project status: P.O.W.E.R. 2.0 is under active development. Verify integrations and follow the security and deployment guidance before production use.
