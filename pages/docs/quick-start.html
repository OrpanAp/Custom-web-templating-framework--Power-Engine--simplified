POWER 2.0 · NODE.JS ≥ 22.13

Quick start

Get P.O.W.E.R. 2.0 running locally, configure the environment, and make your first server-rendered page.

01 · Requirements

  • Node.js 22.13.0 or newer (the framework uses built-in SQLite).
  • Git, or download the source ZIP from the repository archive.
  • A terminal: PowerShell, Command Prompt, macOS/Linux terminal, or Git Bash.

02 · Download the source

git clone https://github.com/OrpanAp/power-2.0.git
cd power-2.0

03 · Create your environment file

PowerShell:

Copy-Item .env.example .env

macOS, Linux, or Git Bash:

cp .env.example .env

The example configuration uses a local SQLite database, so you can explore without installing a separate database server first.

04 · Start the server

node bin/power-cli.js serve

Open http://127.0.0.1:3000. On first boot, the app may create the initial administrator account and print a generated password. Keep it private and change it after signing in.

05 · Explore the app

PathPurpose
/Application landing page
/docsFramework documentation
/demoInteractive feature examples
/adminAdministrator dashboard
/presentationsPublic presentation decks

06 · Create a controller

node bin/power-cli.js make:controller Hello

Then create a view under app/views/ and register the route in app/routes/web.js. For the full request pattern, continue to Routing & middleware.

Run tests

npm test

See the CLI reference for all supported commands.

Project status: P.O.W.E.R. 2.0 is under active development. Verify integrations and follow the security and deployment guidance before production use.
